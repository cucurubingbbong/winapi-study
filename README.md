# WinAPI32 공부

C++와 Win32 API로 창, 입력, 렌더링, 게임 루프를 구현하는 학습 레포입니다.

## 진행 순서

- [ ] 창 생성과 메시지 루프
- [ ] 키보드/마우스 입력
- [ ] 화면 출력과 시간 측정
- [ ] 게임 루프와 객체 이동
- [ ] 충돌 처리와 장면 전환
- [ ] 작은 2D 게임 제작

Windows와 Visual Studio에서 예제를 만들 예정입니다. 프로젝트별 빌드 방법, 실행 화면, 구현 내용을 코드가 추가될 때 기록합니다. 완성작이 생기면 별도의 포트폴리오 레포로 정리합니다.
